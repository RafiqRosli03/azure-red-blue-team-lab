# Detections

- `kql/` — hunting + detection KQL queries, tied to real lab telemetry, with field-by-field
  explanations and difficulty progression (beginner → advanced).
- `sentinel/` — scheduled/NRT analytics rules built from the KQL, with frequency, period,
  threshold, severity, MITRE mapping, entity mappings, incident config.
- `defender/` — Defender for Endpoint / XDR advanced hunting queries and investigation notes,
  including an honest note on which attacks Defender will NOT detect and why.
